# SPORTLYTICS
### The Numbers Behind the Game

Football Performance, Financial Value & Context Analytics.

Sportlytics is a football data analytics and research project
investigating player performance, career progression, transfers,
market valuations, teams and opponents.

## Project Status
Initial Development

## Technology Stack
- Python
- Pandas and NumPy
- DuckDB and SQL
- Jupyter Notebook
- Matplotlib and Seaborn
- Streamlit

## Project Structure
- data: Dataset storage
- docs: Project documentation
- notebooks: Data analysis
- sql: SQL queries
- src: Python source code
- dashboard: Interactive dashboard
- reports: Research findings
- tests: Validation

## Research Approach
Data Collection -> Data Cleaning -> Exploration ->
Analysis -> Statistical Investigation -> Visualization
